# ES6 Classes - Tasks Overview

## Project Overview
This repository contains solutions for the **ES6 Classes** module of the Web Backend curriculum at Holberton School. The primary focus of this project is to learn and master Object-Oriented Programming (OOP) principles in modern JavaScript (ES6), including class declarations, constructors, private property conventions (underscore naming), getters, setters, inheritance, static methods, and symbol properties.

---

## Tasks Summary
